# Hi, I'm HongYu 👋

I'm a master's student working across **infrastructure, full-stack software, and computer vision**. I like designing systems from the interface down to the API, data, workers, and deployment. My current research focuses on Sim2Real vision for sports, especially volleyball and basketball. If a tool I want doesn't exist, I often build it.

[![GitHub](https://img.shields.io/badge/GitHub-henry753951-181717?style=flat-square&logo=github)](https://github.com/henry753951) [![Email](https://img.shields.io/badge/Email-me%40hongyu.dev-0A7C86?style=flat-square&logo=gmail&logoColor=white)](mailto:me@hongyu.dev)

## What I work on

- **Infrastructure & system design:** containerized services, networking, storage, CI/CD, Terraform, and distributed task processing—including parallel GPU workers on Kubernetes.
- **Frontend & backend:** web and desktop interfaces, APIs, databases, real-time communication, and video workflows.
- **Computer vision & simulation:** synthetic data, detection and tracking, pose, camera geometry, multi-camera video, and sports analysis.
- **Tools for my own needs:** small apps, CLIs, and developer tools that make a specific workflow easier.

## A few public examples

**Vision & simulation**

- [NeuralCourt Basketball](https://github.com/henry753951/neuralcourt-basketball) — a **Unity / C#** basketball simulation with GPU-batched character motion and multi-camera monitoring.

**Full-stack applications**

- [Volleyball Monitoring AI](https://github.com/henry753951/volleyball-monitoring-ai) — live annotation and video workflows across **Nuxt / Vue / TypeScript**, **Fastify / GraphQL Yoga / Prisma / PostgreSQL**, and **Redis / MinIO / WebSocket / FFmpeg / OvenMediaEngine / Traefik**.
- [PatentsHub](https://github.com/henry753951/PatentsHub) — a desktop application using **Electron / Nuxt / Vue / tRPC / Prisma**.

**Tools I built because I needed them**

- [TartUI](https://github.com/henry753951/TartUI) — a **SwiftUI** interface for managing Tart images and virtual machines on macOS.
- [k8s-mig-manager](https://github.com/henry753951/k8s-mig-manager) — a **Bun / TypeScript / Ink** CLI for NVIDIA MIG profiles on Kubernetes nodes.
- [Snip](https://github.com/henry753951/snip) — a **SwiftUI / yt-dlp / FFmpeg** app for downloading and clipping video.
- [Cloudflare Catch-all Mailbox](https://github.com/henry753951/cloudflare-catchall-mailbox) — a searchable inbox API built with **Workers / D1 / R2**.
- [Nuxt Imperative Modals](https://github.com/henry753951/nuxt-imperative-modals) — a **Nuxt / Vue / TypeScript** module for opening typed modals from code.
